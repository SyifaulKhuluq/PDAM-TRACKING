# PDAM Water Tracker Pro - Android Studio Project

## Cara Build APK:
1. Buka Android Studio (Ladybug 2024.2+ / Hedgehog+)
2. File > Open > Pilih folder ini
3. Jalankan Gradle Sync
4. Untuk Debug APK: jalankan './gradlew assembleDebug'
   File APK di: app/build/outputs/apk/debug/app-debug.apk
5. Untuk Release APK: Build > Generate Signed Bundle / APK
